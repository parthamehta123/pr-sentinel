How feedback works

Minimum evidence rule: A single dispute doesn't change anything. After {{ 3 }} disputes with the same pattern, the reviewer learns to weight those findings lower.

Decay: Old feedback loses weight over 90 days. A convention that changed 6 months ago won't suppress current findings.

Injection: Active preferences are injected into agent prompts as "team conventions" — the reviewer adapts without manual prompt editing.
